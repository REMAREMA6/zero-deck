## 1. Cross-feature invariants

1. Authentication establishes identity; it does not itself grant Pro, owner activation or file/provider permissions.
2. Protected decisions use authoritative state, not client-supplied claims.
3. MVP-03 provider dispatch requires both independent gates to be positively established; false or unknown state means no call.
4. File analysis does not modify the selected original and does not upload file content by default.
5. Quarantine is not complete until artifact creation, integrity verification and source-disposition status are recorded.
6. Restore requires fresh analysis, explicit confirmation and integrity verification.
7. External failures and incomplete analysis are never represented as clean/successful outcomes.
8. Platform-specific capability differences must be disclosed rather than hidden behind false parity.
9. Retention, deletion, backup, audit and recovery rules must be coherent across data categories.

## 2. Matrix limitation

This is a product-level interaction matrix derived from the declared contracts and existing scenario assessments. It is not an executable test suite, runtime trace, implementation architecture or proof that any ZeroDeck workflow currently works.
