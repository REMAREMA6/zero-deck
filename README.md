# Zerodek — Android security scanner

The Zerodek project: turning the original 17-screen security scanner mockup app
(source project by LordWhitefire) into real software.

This repository is the complete working record of the project:

- `re/` — the **reverse-engineering agent workspace**: `agent.md` (the agent's rules)
  and `skills/` (18 rule files — `eh-*` security-framework checklists and `re-*`
  methodology skills), plus `re/oss-recon/` with the open-source recon decision report.
- `product-management/` — the **product-management agent workspace**: the PM agent's
  framework (`agent.md`, `skills/`, `framework/` with its knowledge base, engine and
  mental models) and the scanner product design artifacts
  (`plan`, `circles`, `scanner-product-design/00–06`).
- `RULES.md` — the project's ground rules.

**Note:** this repository is kept private on purpose — the PM agent's knowledge base
contains full-text book extracts used as reference material.

Original app project: https://github.com/lordwhitefire/Zerodek
