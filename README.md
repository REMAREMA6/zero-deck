# Zerodek — Android security scanner

The Zerodek project: turning the original 17-screen security scanner mockup app
(source project by LordWhitefire) into real software.

This repository is the working record of the project. Agent definitions
(agent identities, skills, frameworks, mental models) are intentionally kept
out of this repository — they live with the owner and are provided to the
agents at runtime.

- `re/` — reverse-engineering agent workspace (work artifacts only):
  `re/oss-recon/` — the open-source recon decision report and raw extract.
- `product-management/` — product-management agent workspace (work artifacts only):
  `plan-2026-11-24.md`, `circles-2026-11-24.md`,
  `scanner-product-design/2026-11-24/` (00–06).
- `RULES.md` — the project's ground rules.

Original app project: https://github.com/lordwhitefire/Zerodek
